    FAQ

    Common questions about per-page rotation.

    Does this change the content of my PDF?
    No — it only changes page orientation for pages you rotate.
    Can I rotate different pages by different amounts?
    Yes — click pages individually to set their rotation before downloading.
    Will the file size change?
    Usually it stays similar. Rotation typically updates page metadata.

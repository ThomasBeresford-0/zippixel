    FAQ

    Common questions about rotating PDFs.

    Does this change the content of my PDF?
    No — it only rotates page orientation. Text and images remain the same.
    Can I rotate by different degrees per page?
    Not on this page yet — this tool applies one rotation to the whole PDF.
    Will the file size change?
    Usually it stays similar. Rotation updates page metadata without re-encoding images.

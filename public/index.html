    FAQ

    Common questions about PDF compression.

    Will compression change how my PDF looks?
    Balanced aims to keep layout and clarity. Maximum may reduce image detail more aggressively to shrink size.
    Which level should I use?
    Use Balanced for general use, Light for higher quality, and Maximum when you need to meet strict upload limits.
    Do you support multiple PDFs here?
    Compress PDF is designed for a single file. Use the ZIP tool if you want to bundle many files for download.
